# Android UI 设计基准（用户截图，2026-09-26）

## 基准与范围

本规范以用户提供的三张 ChatGPT Android 手机截图为视觉基准：空白聊天页、展开的左侧抽屉、已有图片和长文本的对话页。原图暂存在本地 `.reference/` 供逐屏对照，并由 `.gitignore` 排除；不把包含个人会话内容的原图提交到开源仓库。

这三张图确定的是页面结构、密度、排版与交互位置，不代表要复制 ChatGPT 的品牌、文案或尚未具备的功能。后续 UI 实现时，对照原图逐屏验收。

## 1. 空白聊天页

- 全屏白底，Android 系统状态栏和手势导航条保持系统样式。页面中部大面积留白，不放营销插画、配额卡片或功能卡片。
- 顶部左侧是圆形菜单按钮；中间是浅灰底的「聊天 / 工作」分段切换，选中项为白色胶囊；右侧是圆形快捷入口。
- 输入栏固定在底部安全区域上方：大圆角白色容器，左侧加号，中间提示文字，右侧语音图标和蓝色圆形主按钮。输入栏与屏幕边缘留有明显间距。
- 最近内容可在输入栏上方以简短文本行展示；不使用独立大卡片。

## 2. 左侧抽屉

- 抽屉覆盖约屏幕宽度的八成，右侧页面加灰色遮罩。抽屉本身为白底。
- 顶部采用大号产品名和独立圆形搜索按钮。
- 主要功能入口使用图标加文字的纵向列表，行间距宽松，不放灰色卡片底。
- 会话按「置顶」「最近」等时间或固定分组排列。标题直接成行，选中态只用轻微底色或文字强调。
- 底部固定蓝色圆角「聊天」主按钮和账号入口。
- 产品功能名称须映射到本项目已有能力；不照搬参考图中的图片库、定时任务、插件等入口。

## 3. 已有消息的对话页

- 用户消息靠右，使用浅蓝色圆角气泡。用户发送的图片以大圆角附件预览显示。
- Agent 回复直接排在白色页面上，不套整段灰色气泡。正文采用清晰的标题、段落、列表和代码块层级，左右边距一致。
- 消息操作采用低对比度的图标行；工具执行与待确认操作按本项目业务状态呈现，避免覆盖正文。
- 输入栏在已有对话中可增高为两行：提示文字位于上行，加号、语音和蓝色主按钮位于下行。软键盘弹出时随键盘上移。
- 顶部菜单、新建会话和更多操作保留可触达的圆形或胶囊触控区。

## 视觉约束

| 项目 | 方向 |
| --- | --- |
| 背景 | 白色，少量浅灰用于选中状态和输入栏 |
| 文字 | 主文字近黑，次要文字中灰 |
| 强调色 | 蓝色只用于主要操作和少量状态 |
| 容器 | 不使用旧版首页的大量灰色会话卡片 |
| 动效 | 抽屉滑入、分段切换、输入栏随键盘移动，时长保持克制 |
| 适配 | 以 dp 和安全区实现；验证窄屏、长标题、中文换行及系统字体放大 |

## 首版实现决策

- 技术栈保留 Kotlin + Jetpack Compose，Compose BOM 升至 `2026.09.00`。
- 首版只做空白聊天、左侧抽屉、已有消息聊天三种静态状态；菜单、示例会话、新建聊天提供本地切换。
- 图标使用 Google Material Symbols 的精简字体子集；示例附件是无个人信息的本地图片。
- 「工作」、搜索、远程控制及语音入口先仅展示，不连接网关、不发送网络请求。真实行为需后续按接口定义实现。

旧版 `android-ui-concept-v2` 的卡片式设计不再作为实现依据。
