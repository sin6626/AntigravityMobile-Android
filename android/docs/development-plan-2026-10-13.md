## 开发顺序

每一批都一起交付视觉、交互、动画和异常状态。先做截图与操作复现，再修改；禁止为了减少代码取消已有动画或把失败状态藏起来。

### 第一批：让入口清晰可信

本批三项已分别完成并提交，复用已有组件和协议，没有增加后端接口。以下保留验收范围。

1. 统一附件入口的能力说明与选择范围。保留用户确认的拍照/照片/文件菜单布局，在进入系统选择器前明确“文件”当前只支持图片，并限制可选格式。如果目标是上传任意文件，则先确认后端上传、大小限制、存储、消息附件字段与模型能力，再写对应页面。
2. 给同名项目显示用于区分的工作区信息。只在需要区分时展示已有路径或 URI 的简短信息，长内容有可读的完整查看方式；名称、稳定 ID、展开状态和真实项目归属保持一致。不得按名称去重。
3. 项目创建不可用时显示具体原因及可操作的恢复入口，例如模型目录加载/失败、正在创建。复用现有状态和目录重试，不新增一套状态管理。

UI / 动画验收：菜单版式、图标、阴影和点击区域保持当前规范；补说明不能造成菜单瞬间变高或挡住输入框；项目展开/收回、中途反向操作、刷新和重排保持连续，同名项目不串状态。错误反馈持续可见且可恢复。

功能验收：支持的图片可以选择，不支持的文件不造成草稿丢失；两个同名项目各自打开正确会话；模型目录失败→重试→可以创建，忙碌期间不能重复创建。仅在独立测试会话执行写操作。

涉及文件：`ChatDemoScreen.kt`、`ChatComponents.kt`、`ProjectOverview.kt`、`DemoDrawer.kt`；按需要使用现有 `ProjectItem`、`ChatViewModel` 和 `ChatUxTest`。先核对全部调用方，不引入通用文件上传抽象。

### 第二批：输入到阅读的连贯体验

用固定回复样例录屏核对聚焦输入→键盘打开→模型面板→快速完成→输入→发送→流式结束→回看历史。已有能力保留，只修复本轮复现的跳位、误触或反馈缺口。

- 核对 1～4 行文字、0～4 张附件、连续移除附件和发送/停止切换；输入框、阴影、按钮和列表底部留白一起运动，键盘返回仅先收起键盘。
- 流式结束切到标题、代码、表格、公式/图表时保持阅读锚点；用户阅读历史时不被拉回底部，历史不重复播放入场动画。
- 核对顶部渐隐区域、浮动按钮与正文的关系，使用当前已确认的字号与视觉，不凭审美重新改整页。
- 固定复杂 stateDiagram 样例检查拥挤问题，确认属于布局还是显示尺寸后再决定修复点。

验收包含慢速逐帧和快速反向操作，复用 `MotionTest`、`ExecutionPanelTest`、`ReplyMediaAndCopyTest`；截图只验证布局，动画需要录屏或逐帧断言。性能使用实际包与相同内容测量，不能引用旧 Release 数据宣称本轮更快。

### 第三批：导航、图片与适配补验

- 首页、项目、归档、抽屉搜索往返，检查当前项、搜索清空、滚动位置、展开状态和草稿；首页布局调整先取得认可的参考图。需要图片直接向用户索取切图，不手绘替代。
- 原图双击缩放、双指跟手、边缘换页、关闭重开及失败重试，检查连续性与误触。确认大图内存问题后才引入采样或限制，避免无证据增加图片框架。
- 现有模拟器检查字体放大、长模型名、长项目名、TalkBack 操作描述、48 dp 点击区域和关闭动画；临时系统设置必须恢复。
- 测量当前会话规模下抽屉/项目展开滚动帧与首帧。如果确有批量组合造成的卡顿，再用现有懒列表替换对应容器，并保留搜索、长按、展开和菜单语义。

### 后续能力，不并入今天首批

- 语音输入/聊天：先确定交互参考、录音权限、识别与合成提供方、取消与失败恢复、后端协议，再实施。现有入口需要准确说明可用性。
- 任意文件上传、PDF 等预览、全文搜索：各自明确协议与用户需求后立项，不能把“文件”文案修正算成这些能力已完成。
- 通知直达继续遵守用户暂缓决定；恢复时先确定接收方式，区分通知会话深链与配对链接。目前 `MainActivity` 把进入链接交给 `pair`，尚未实现完整会话深链分流。
- 真机长历史、真实蜂窝/VPN 切网和长时间后台恢复：安排独立验收，当前模拟器与此前无历史的性能采样不能替代。

## 每批交付要求

1. 先列正常、加载、失败、重试、快速反向和关闭动画的路径，再动代码。图片资源和接口枚举不清晰时，向用户说明缺什么，等待资料后完成依赖部分。

3. 运行与改动相符的现有单测、构建和模拟器回归。新状态逻辑留下最小有效回归；只改文案不加镜像测试。新接口继续经 `ApiTraceInterceptor` 输出请求、头、参数、状态与响应，凭据保持脱敏。

5. 每批更新 `Agent.md` 与本文状态，用中文 Conventional Commits 提交；临时文件放当前项目内，不批量删除，不关闭用户模拟器。
