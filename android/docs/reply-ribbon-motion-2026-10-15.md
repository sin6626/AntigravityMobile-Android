# 回复等待动效重做与验收

日期：2026-10-15。用户否定上一轮通用转圈的观感，要求把 UI 和动画质量作为第一原则，达到 SVG 动画般连续、丝滑的视觉效果。本次替换原生加载圈，保留已有状态处理和即时正文渲染。

## 视觉与节奏

| 元素 | 本轮实现 |
| --- | --- |
| 主形态 | 32 dp 蓝紫渐变闭合光带，四段 Bézier 曲线形成交织的双环 |
| 循环 | 2,800 ms 线性时间轴；形变、倾斜与呼吸使用周期函数，循环前后连续 |
| 流动 | 高光沿路径长度前进，跨越闭合接缝时连续拼接，不到头倒放 |
| 层次 | 1.8 dp 主线，低透明度外沿，青色→蓝色→紫色渐变 |
| 留白 | 固定 32 dp 槽位，与状态文字间距 10 dp，垂直居中 |
| 首段衔接 | 正文立即显示；光带 260 ms 淡出，同时收束到 72%，文字不横移 |
| 关闭动画/后台/离屏 | 显示静态矢量形态，停止无限动画；不阻塞正文 |

使用 Android Compose 原生矢量绘制，没有嵌入 SVG 网页或引入动画依赖。时钟只在 Canvas 绘制阶段读取；路径和测量对象复用，动画不会触发正文解析或文字布局。仍沿用已验证的发送、审批、断连、停止、结束和轮次判断。

## 实际验证

- Debug 和 AndroidTest 构建成功，已保数据覆盖安装 API 37 模拟器。
- 11 项聚焦 UI 用例通过：7 项等待/衔接/状态/尺寸/后台检查、真实页面假网关链路、实际 Android 时钟播放、回到底部不闪、关闭动画时正文即时显示。
- 尺寸继续覆盖 320/360/412 dp 与字号 1.0/1.5，光带与文字不重叠，衔接时文字位置稳定。
- 实际时钟用例覆盖多个循环，并检查首段之后光带消失、生成中的状态行静止、结束后移除。录制并检查了等待和衔接画面。
- 无录屏时，6 秒获得 360 个窗口帧回调，P95 总帧耗时 18.82 ms，超过 32 ms 的帧数为 0。录屏时同样 6 秒为 355 帧，P95 29.12 ms，超过 32 ms 为 5 帧。数据仅代表该模拟器与该等待场景，不代表真机或复杂正文的帧率保证。
