# 回复等待动效重做与验收

日期：2026-10-15。用户否定上一轮通用转圈的观感，要求把 UI 和动画质量作为第一原则，达到 SVG 动画般连续、丝滑的视觉效果。本次替换原生加载圈，保留已有状态处理和即时正文渲染。

## 视觉与节奏

| 元素 | 本轮实现 |
| --- | --- |
| 主形态 | 32 dp 蓝紫渐变闭合光带，四段 Bézier 曲线形成交织的双环 |
| 循环 | 2,800 ms 线性时间轴；形变、倾斜与呼吸使用周期函数，循环前后连续 |
| 流动 | 高光沿路径长度前进，跨越闭合接缝时连续拼接，不到头倒放 |
| 层次 | 1.8 dp 主线，低透明度外沿，青色→蓝色→紫色渐变 |
| 留白 | 固定 32 dp 槽位，与状态文字间距 10 dp，垂直居中 |
| 首段衔接 | 正文立即显示；光带 260 ms 淡出，同时收束到 72%，文字不横移 |
| 关闭动画/后台/离屏 | 显示静态矢量形态，停止无限动画；不阻塞正文 |

使用 Android Compose 原生矢量绘制，没有嵌入 SVG 网页或引入动画依赖。时钟只在 Canvas 绘制阶段读取；路径和测量对象复用，动画不会触发正文解析或文字布局。仍沿用已验证的发送、审批、断连、停止、结束和轮次判断。

## 同日追加：状态文字流光

用户认可左侧光带，要求继续优化纯文字。现在「正在回复…」采用 14 sp 中等字重和 0.2 sp 字距，一束蓝、银灰、紫的高光从左向右扫过字形，周期 2,800 ms，与原光带共用时钟。正文出现后文字继续流光，直到回复结束；本节替代前文「生成中的状态行静止」的要求。停止、后台、离屏及系统关闭动画时文字保持静止。

复用 Compose 的缓存画刷和局部离屏混合，保留 Text 的布局与无障碍语义；时钟仅在绘制阶段读取，未增加依赖。实现参考 [Android 官方图形修饰符说明](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)。

Debug/AndroidTest 构建通过，10 项不同的聚焦用例全部通过。新增文字本身在等待和正文阶段的像素变化断言、停止后的静止断言，补充后台/离屏/关闭动画时文字静止与恢复检查；原首段即时显示、状态切换及 6 组尺寸字体回归通过。实际平台时钟用例通过，另为完整录屏复跑一次通过。检查实际帧序列与等待/正文截图，未发现文字位移或矩形色块。录屏干扰下的首次平台采样为 356 帧、P95 30.36 ms、超过 32 ms 共 10 帧，不作为真机性能保证。
