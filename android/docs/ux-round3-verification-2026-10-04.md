# 第三轮动效实施与验收

日期：2026-10-04。基线：第二轮 `4971328`。实施提交：`9f1c682`、`adbf5bf`。第三轮实现与模拟器技术验收完成；第二轮、第三轮仍待用户亲自体验反馈。

本轮只修改 Android 与维护文档，沿用现有白、灰、蓝配色、图标和原生 Compose，无新增依赖。仅操作 `emulator-5554`（API 37），未安装或操控 USB 真机、未发送真实聊天消息、未修改或重启 Go 网关。

## 实际改动

| 场景 | 实现 | 状态保护 |
| --- | --- | --- |
| 输入栏聚焦与多行 | 宽度/圆角沿用 stiffness=350 的无回弹 spring；文字行从固定 58dp 改为最小 58dp，最多四行随内容增高，180ms 尺寸过渡 | 同一个 BasicTextField 保留焦点、文字和光标；移除父容器的重复高度动画 |
| 附件与操作行 | 托盘、下方操作行各负责自己的 180ms 展开/收起；图片 120ms 淡入，中间删除后原生 LazyRow 按 URI 重排 180ms，删除立即生效 | 退出中的旧操作立即禁用并移除语义，保留 48dp 触达区域；不保留已删除图片的计时队列 |
| 发送/停止 | 保留固定按钮圆面与 120ms 内部 Crossfade | 忙碌和禁用立即生效，退出中的旧按钮不能提交 |
| 会话/页面进入 | 只对当前内容做 140ms 淡入，项目/归档层级进入和返回增加 10dp 横向位移、180ms 过渡 | 首次消息定位后开始；HTTP/流式刷新不重播；抽屉关闭后再进入；Pager 与抽屉仍由原生手势驱动 |
| 大字体进入 | fontScale≥1.3 时取消横向位移，只淡入 | 内容与操作保持可读，不改变导航语义 |
| 更多菜单 | 原生 Popup 内 AnimatedVisibility：150ms 淡入+0.96→1 微缩放，110ms 退出，锚点在右上角 | 出场结束再移除；关闭时立即禁用操作、清除旧语义并释放焦点；切换会话直接移除旧弹层 |
| 项目展开 | 原生顶部对齐 200ms 展开/收起，150/120ms 淡入/淡出 | 保留项目稳定 key、展开集合与列表位置，不叠加父级尺寸动画 |
| 流式结束 | 保留后台 Markdown 块解析与末块稳定 key；以滚动意图区分跟随和阅读历史 | 正文自身增高不被误判为用户离开底部；用户滚动/展开过程停止跟随，回到最新后恢复；没有逐帧滚动补偿 |
| 运行中关闭动画 | 流式呈现读取协程中的原生 MotionDurationScale，比例切为 0 时结束待展示文字 | 不需要下一条服务器消息；内容仍以服务端文本为准 |

执行过程 220ms 顶部展开、复制对勾、本地新消息 180ms 入场、回到最新按钮与图片预览保持原有行为；本轮回归其位置、选择和点击语义。语音、预测性返回、共享图片转场与渲染引擎替换不在此次实现范围内。

原生动画关闭行为与协程比例的依据见 [MotionDurationScale 官方说明](https://developer.android.com/reference/kotlin/androidx/compose/ui/MotionDurationScale)。系统键盘仍由 `imePadding()` 避让，未给键盘高度叠加额外弹簧。

## 复现与验证

合成样例复现了两个真实布局问题：

- 四行输入受固定高度限制，第一行被裁切；同一字体下字段高度由一行 64px 到多行 152px。候选版四行高度 235px，第一行到第四行完整可见。
- 流式纯文本增高后，结束时只看当前布局是否靠近底部，会丢失跟随意图；合成标题、加粗、代码、表格样例完成后末尾曾留在屏外。修正后末尾仍显示；滚到历史第一条再更新和完成回复，历史标题坐标保持在 1px 误差内。

## 录屏与帧数据的解释

使用独立 `NativeMotionPlaybackTest`，由 Android 真实帧时钟运行，复用与主页面相同的 edge-to-edge、adjustResize 和外层键盘避让布局。合成操作包括聚焦、一到四行、四张附件、中间删除、清空附件、收键盘和更多菜单开合。没有复制测试时钟的快进结果来证明正常播放速度。

前后录屏保存在忽略目录 `android/design/.verification/round3-native-baseline.mp4` 与 `round3-native-motion.mp4`。局部连续帧核对了输入栏从顶部增高、按钮在键盘上方、菜单从右上角淡入微缩放及淡出。Activity 启停和录屏首尾不作为应用转场效果。

退出测试后进程会结束，外部 `dumpsys gfxinfo` 曾返回 No process；最终改为在夹具退出前采集，保存了有效数据：

| 第二轮基线 | 83 | 71（85.54%） | 93ms | 500ms | 1250ms |

## 用户体验反馈后的修正（2026-10-04）

用户否定图片查看中的文字控件、搜索清空文字、会话顶部状态行、选中项对齐及气泡内部的复制/Undo。本次仅围绕这些反馈修正，不开做后续新功能，不安装或操作真机。

- 全屏图片只显示图片与黑色底色；HorizontalPager 原生手势翻页，双指缩放、单指拖动放大图片、拖过边缘再翻页，双击放大/恢复。标题、序号和文字控件全部移除，系统返回退出；失败只显示重试图标，无障碍仍有前后图片/缩放/退出动作。聊天图片、Markdown 内图片与图片文件查看使用同一查看器。
- 抽屉与归档搜索的清空操作改为框内 ×，空输入时隐藏。会话行保留浅灰选中底色，文字左对齐、垂直居中、左右留白一致；仅修改会话行，保留项目缩进/展开与其他入口。
- 会话顶部连接、重试和等待文字行移除；加载仅显示原有居中动画，失败仍可下拉重试。下拉重读 HTTP 消息并重连 WebSocket，已有消息和草稿保留。长会话下拉刷新需先滚到列表顶部，正常下拉浏览历史继续遵循原生列表滚动。
- 用户消息气泡内只保留文字/图片，复制和 Undo 移到气泡下方靠右；图标20dp、点击范围48dp。运行/发送/回退/管理忙碌时不显示回退，明确不支持的消息也不显示灰色按钮。
