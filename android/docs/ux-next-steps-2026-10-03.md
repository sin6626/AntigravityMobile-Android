## 第二轮：阅读与恢复体验

已按 2.1 → 2.2 → 2.3 → 2.4 实施，复用现有状态、组件、接口、Coil 与原生 Compose，未增加依赖。以下保留本轮范围和验收标准，实际结果与限制见第二轮验收记录。

### 2.1 断线、加载与失败恢复

现有入口：`StreamWebSocketClient.connectionStatus` 与自动重连、`ChatViewModel` 的消息/列表读取、`ChatDemoScreen` 和 `ConversationContent` 的状态展示。

- 将真实连接状态接入页面，区分正在连接/重连、生成中、等待用户和读取失败；连接状态与 Agent 运行状态分别处理。
- 首次消息/会话列表读取失败时提供持续可见的重试入口；已有内容刷新失败时保留内容与草稿，不用空态替换。
- 重连成功重新同步当前会话历史和运行状态，避免漏掉断线期间的消息；重试防重复，延迟结果只能更新原会话及原次进入。
- 鉴权失效沿用重新配对流程；其他网络错误保留可恢复的阅读与输入状态。网络提示采用现有风格的轻量状态展示。

验收：模拟器断网→恢复网络；首次加载失败→重试成功；阅读中刷新失败；重连期间 A→B 切换；授权失效。确认旧消息/草稿不丢、消息不重复、断线不被当成生成完成、B 不被 A 的迟到结果覆盖。

本项关注 App 状态与恢复流程；CF/Clash 配置故障另见 [隧道故障记录](cloudflare-tun-diagnosis-2026-10-03.md)。

### 2.2 图片查看

现有入口：聊天图片与预览组件、`LinkedFilePreview`，以及 `ApiClient.resolveMediaURL` 的鉴权与原图访问。

- 聊天缩略图和大图补失败重试，预览提供明确关闭按钮与系统返回行为。
- 大图支持双指缩放、拖动及合理边界；图片切换或重新打开时恢复查看状态，缩放/拖动手势不误触关闭。
- 统一核对聊天附件、回复内图片与文件预览图片的加载/失败行为，保留原始文件 URI 和授权链路。
- 沿用现有图片加载依赖，先检查其与 Compose 原生手势能否满足需要，再决定是否增加依赖。

验收：竖图、横图、长截图、多图；加载中关闭；请求失败后重试；缩放后拖到边缘；关闭并重开；受保护原图访问。确认图片可看清、关闭可靠、失效图片不占一块无法解释的空白。

### 2.3 搜索与列表反馈

现有入口：`DemoDrawer`、`ProjectOverview`、首页最近会话和 `ArchivedConversations`。目前搜索范围为已加载的标题/项目名。

- 区分尚无数据、没有匹配结果、正在加载和加载失败；搜索提供清空入口。
- 抽屉标识当前会话；置顶、最近、项目与归档继续遵循第一轮的归属与过滤规则。
- 项目展开身份使用稳定项目标识，核查 ID/URI 缺失及重复情况后处理，避免依赖过滤后下标；刷新、搜索和重排保留展开状态。
- 记录实际会话规模与滚动表现，有证据后再决定是否改抽屉懒列表。

验收：中文/英文、空字符串、无匹配、清空搜索；选中会话；搜索过滤后清空；项目重排/刷新；置顶与归档恢复。确认空态准确、展开身份不串、归档项不会混入活动列表。

### 2.4 点击区域与无障碍

现有入口：`ChatComponents` 的按钮/附件操作、图片关闭/重试、列表与状态反馈。

- 核查按钮点击区域，目标为 48 dp 触达尺寸，保持图标视觉尺寸和现有布局。
- 补图标操作描述、选中/禁用/忙碌状态，确保重复点击不会重复提交。
- 未实现的语音入口采用准确提示或清晰不可用状态，文案须承认已有图片能力。
- 核对字体放大、TalkBack 和系统关闭动画；轻触反馈只用于明确操作，不随流式更新触发。

验收：附件删除、添加图片、关闭预览、重试与更多菜单可准确点按；TalkBack 能识别操作与状态；大字体不遮挡关键操作；关闭动画后功能仍完整。

| 3.2 输入栏与附件 | 多行文字、4 张附件、附件删除、发送/停止状态切换与键盘开合统一反馈 | 保留同一个输入框；高度变化自然；快速开合/连续移除无跳位，键盘返回不误退出会话 |

验收材料：固定回复样例和录屏、开合与滚动位置检查、模拟器长消息阅读；后续真机性能以当轮实际数据评估，不复用旧测量宣称新动效更快。

## 后续功能与接口前置条件

完成第二、三轮后，从下表按优先级逐项选择实施，先核实协议再写页面。

| 优先级 | 功能 | 开发前必须明确 | 最小验收目标 |
| --- | --- | --- | --- |
| 1 | 项目内新建会话 | `createCascade` 的 projectId/workspaceUri、模型及实际项目归属；缺失/无效项目的失败语义 | 在明确测试项目内创建、发送并重新读取归属；失败不误建到普通聊天 |
| 2 | 模型选择 | 当前账号真实可用目录、默认项、额度与不可用原因、已有会话切换语义 | 列表来自真实协议；新建/切换生效；失败保留原模型，回退仍保持配置 |
| 3 | 通知直达会话 | 配对与 session/cascade 深链分流、目标 ID、授权校验；通知权限、Token 注册与后台送达配置 | 先验证前台/后台/冷启动的正确跳转，再验证真实推送；不把深链通过当成推送链路通过 |
| 待明确 | 多选问题 | 选项数组字段、问题标识、提交/取消语义 | 正确提交多个选择，不能拼接单个 optionId 冒充多选 |
| 待明确 | 语音输入 | 识别服务、权限、成本、隐私与失败恢复方式 | 先做语音转文字，识别结果可编辑后发送；完整实时通话另行规划 |
| 待明确 | 图片草稿跨进程恢复 | URI 持久权限或缓存方案、恢复与清理策略 | 进程重启后恢复有效附件；失效时明确提示，不阻止其他草稿操作 |

完整文件编辑器、终端/远程控制、全文搜索后端、渲染引擎替换与大面积主题重做暂不排期；出现明确需求后再评估。

## 实施与验收约束

- 当前阶段继续优先用模拟器，真机按用户后续安排验证；第二轮仅安装模拟器，未发送消息或重启服务。此计划本身不触发下一轮操作。
- UI 沿用现有白色/灰色/蓝色风格和已提供参考；需要新图片资源时向用户索取，不手绘 CSS/SVG 替代切图。复用原生组件与已有官方图标。
- 接口不明确时停止依赖该协议的开发，列明缺失细节交用户确认；不按示例猜枚举或多选协议。保持 `API_TRACE` 结构化请求/响应日志及敏感字段隐藏。
- 异步操作捕获会话身份；校验断线、返回、切换、重复点击等路径，保留已有消息与草稿。
- 真实发送、删除及回退验收使用临时会话，文件回退使用隔离工作区；材料仅存项目内忽略目录，不展示私人内容，不批量删除文件。
- 每轮记录实际网关版本、端点与测试结果；Go 新增检查与已有 Windows 路径测试失败分别记录，不把排除后通过写成全套通过。
- 第一轮实现与协议研究保留为历史证据；本文件的进度表与后续计划随实施更新，`Agent.md` 保留当轮结果与限制。
